صورت سوال
طراحی یک پلتفرم مدیریت پروژه (مشابه Jira / Asana / Trello / Notion) که:

میلیون‌ها کاربر و میلیون‌ها پروژه در آن مدیریت شود.

کاربران بتوانند پروژه، تسک، برد، تایم‌لاین ایجاد کنند.

Real-time Collaboration با CRDT برای ویرایش همزمان.

Notification برای تغییرات، منشن، ددلاین.

Search پیشرفته در تسک‌ها، کامنت‌ها، فایل‌ها.

Integration با GitHub، Slack، Google Calendar.

Permission بر اساس نقش (Owner، Admin، Member، Guest).

Reporting و Dashboard برای تیم.

File Attachment برای هر تسک.

Time Tracking برای ثبت زمان کار.

GDPR و حذف حساب کاربر.

Multi-language و Multi-currency (برای صورت‌حساب).
