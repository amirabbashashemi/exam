صورت سوال
طراحی یک سیستم مدیریت محتوا (مشابه WordPress / Medium / Ghost) که:

میلیون‌ها کاربر و میلیون‌ها محتوا در آن منتشر شود.

کاربران بتوانند محتوا (پست، صفحه، مقاله) ایجاد کنند.

Real-time Collaboration برای چند نویسنده همزمان.

Versioning با قابلیت بازگردانی به هر نسخه.

SEO بهینه (Sitemap، Meta Tags، Schema).

CDN برای توزیع سریع محتوا.

Media (تصویر، ویدیو، فایل) با مدیریت متمرکز.

Comment و Interaction روی محتوا.

Multi-tenant برای چند سایت/وبلاگ مستقل.

Template و Theme قابل سفارشی‌سازی.

GDPR و حذف حساب کاربر.

Analytics برای نویسنده.

Notification برای Comment جدید، انتشار.
