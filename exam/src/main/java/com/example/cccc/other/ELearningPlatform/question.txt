📝 صورت سوال
طراحی یک پلتفرم آموزش آنلاین (مشابه Coursera / Udemy / فرادرس) که:
میلیون‌ها دانشجو و هزاران مدرس داشته باشد.
دانشجوها بتوانند دوره ثبت‌نام کنند و ویدیو ببینند.

Quiz و Assignment برای ارزیابی وجود داشته باشد.
Progress Tracking برای هر دانشجو نمایش داده شود.
Certificate پس از اتمام دوره صادر شود.
Live Class برای جلسات زنده برگزار شود.
Search پیشرفته برای جستجوی دوره.
Recommendation بر اساس علایق و رفتار دانشجو.
پرداخت برای خرید دوره و درآمد مدرس.
GDPR و حذف حساب کاربر.
