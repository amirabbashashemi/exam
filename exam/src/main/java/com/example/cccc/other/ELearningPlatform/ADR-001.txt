ADR-001: انتخاب معماری ذخیره‌سازی و توزیع ویدیو
وضعیت: پذیرفته شده

زمینه:
میلیون‌ها ساعت ویدیو باید ذخیره و توزیع بشه. اگه از سرور خودمون توزیع کنیم، Bandwidth نجومی می‌شه. کاربر تو ایران نباید برای دیدن ویدیو منتظر بمونه.

تصمیم:
از S3 برای ذخیره‌سازی و CDN چندلایه (CloudFront + Akamai) برای توزیع استفاده می‌کنیم.

دلیل تصمیم:
S3 مقیاس‌پذیری نامحدود داره. CDN ویدیو رو از نزدیک‌ترین Edge Server به کاربر می‌رسونه. اینطوری Latency کم می‌شه و هزینه Bandwidth سرور اصلی کاهش پیدا می‌کنه.

مزایا:

مقیاس‌پذیری نامحدود

Latency پایین برای کاربران جهانی

کاهش ۹۰٪ بار روی سرور اصلی

Durability ۹۹.۹۹۹۹۹۹۹۹۹٪

معایب:

هزینه CDN برای ترافیک بالا

پیچیدگی Multi-CDN

نیاز به Cache Invalidation

وابستگی به AWS

موارد دیگر بررسی‌شده:

ذخیره در دیتابیس: DB منفجر می‌شه، هزینه نجومی

فایل‌سیستم محلی: مقیاس‌پذیری محدود، بدون CDN

فقط CDN بدون S3: CDN برای ذخیره‌سازی طراحی نشده

پیامدها:

مثبت: مقیاس‌پذیری، Latency پایین

منفی: هزینه CDN، Multi-CDN

ریسک: اگه CDN Down بشه → Multi-CDN + Fallback

تصمیم:
از Tiered Storage + Soft Delete + Anonymization + Key Deletion استفاده می‌کنیم:

Warm (۶ ماه تا ۲ سال): Elasticsearch

دلیل تصمیم:
هر داده تو دیتابیس مناسب خودش. Soft Delete Foreign Keyها رو سالم نگه می‌داره. Anonymize حریم خصوصی. Key Deletion برای E2EE.

Compliance با GDPR

Audit Trail حفظ
