ADR-004: پشتیبانی از چندزبانگی، ارز، و Geospatial (Geohashing، ETA)


زمینه و مسئله:


وضعیت:
پذیرفته شده

گزینه‌های بررسی‌شده:
1)استفاده از i18(next) و وجود یک json برای هر زبان
    مزایا:
        مقیاس پذیری
        جداسازی زبانها
    معایب:
        هر زبان نیاز به ساخت فایل json خود دارد
        سربار تغییر زبان وجود دارد

2)hard code شدن همه زبانها
    مزایا:
        ساده بودن پیاده سازی
        تجمیع زبانها
    معایب:
        با هر تغییر در هر زبان نیاز به نسخه گذاری است

3) استفاده از وب سرویس بانک مرکزی برای دریافت نرخ ارز در بازه های زمانی مناسب و تبدیلات قیمت ها به ارز های متفاوت
    مزایا:
        بروز بودن نرخ ارزها
    معایب:
        پیچیدگی پیاده سازی
        وابستگی به سرور خارجی
        سربار در تبدیل ارز ها

تصمیم:

استفاده از i18(next) و وجود یک json برای هر زبان و  استفاده از وب سرویس بانک مرکزی برای دریافت نرخ ارز در بازه های زمانی مناسب و تبدیلات قیمت ها به ارز های متفاوت

پیامدها:
مثبت:
توانایی تغییر زبان در UI فراهم است و در بروزر میتوان بدون تغییر در کد زبان را عوض کرد
منفی:
ممکن است سرویس بانک مرکزی یا خطای ارتباطی وجود داشته باشد و تبدیلات ارزی بروز نباشد و نیاز به پشتیبانی بالاست
