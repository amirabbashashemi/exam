ADR-06: کاربردپذیری (UX) برای خریدار، فروشنده و ادمین (سه نقش)


زمینه و مسئله:
سیستم باید محیط UI کاربران خریدار، فروشنده و ادمین را بر اساس نقش آنها فراهم کند و کاربر پسند باشد
