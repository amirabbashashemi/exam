ADR-05: مدیریت چرخه حیات داده‌ها (سفارش‌های قدیمی، Review، GDPR، Return)

زمینه و مسئله:
سیستم باید چرخه حیات داده‌ها را بر اساس زمان مدیریت کند و بر اساس قانون بعداز گذشت 7 یا 10 سال داده های حساس کاربران یا سفارش ها را حذف نماید.

وضعیت:
پذیرفته شده

گزینه‌های بررسی‌شده:
صمیم ۱: Tiered Storage
    توضیحات: Hot (۲ ماه): PostgreSQL + Redis. Warm (۲-۶ ماه): Elasticsearch. Cold (۶ ماه-۷ سال): S3 Glacier. GDPR (> ۷ سال): حذف.
    مزایا:
    کاهش هزینه (Glacier ارزان‌تر)
    سرعت بالا برای Hot
    Compliance
    معایب:
    تأخیر Restore از Glacier
    پیچیدگی Job
    هزینه انتقال



تصمیم ۲: Return Workflow (Saga)
    توضیحات: کاربر درخواست Return → بررسی توسط فروشنده → تأیید → بازگشت به انبار → Refund. هر مرحله Saga.
    مزایا:
    شفافیت
    Compensating Transaction
    Audit Trail
    معایب:
    پیچیدگی
    تأخیر
    نیاز به هماهنگی فروشنده



تصمیم ۳: Review Moderation
    توضیحات: AI (TensorFlow) برای تشخیص اسپم + تیم انسانی برای موارد مشکوک. Verified Purchase (فقط خریداران).
    مزایا:
    حذف اسپم
    اعتماد کاربر
    کاهش Fake Review
    معایب:
    هزینه AI
    False Positive
    زمان بررسی
