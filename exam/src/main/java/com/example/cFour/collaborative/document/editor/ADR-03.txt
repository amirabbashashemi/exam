ADR-03: پیکربندی آسان برای کاربر (Permission، Sharing، Templates، Plugin)

زمینه و مسئله:
سیستم باید ایت قابلیت را داشته باشد که براحتی بتوان یک سند را share کرده و یا از template های مناسب برای تغییرات استفاده کرد و با دسترسی ها متفاوت بتوان محدودیت ایجاد نمود

وضعیت:
پذیرفته شده

گزینه‌های بررسی‌شده:
استفاده از template های آنلاین
مزایا:
    سادگی در استفاده
    پیاده سازی آسان
معایب:
    وابستگی به سایت فراهم کننده
    وابستگی به اینترنت
    نیاز به منابع مالی در صورت رایگان نبودن و عدم کیفیت سایت های رایگان


استفاده از هوش مصنوعی
مزایا:
    سادگی در استفاده
    پیاده سازی آسان
معایب:
    وابستگی به AiAgent
    پیچیدگی در پرامپت دادن


استفاده از لایبرری ها و Templates های آماده لوکال و پیاده سازی با زبان برنامه نویسی و قابلیت افزودن Plugin
مزایا:
    کنترل بیشتر در تغییرات
    عدم وابستگی به اینترنت و سایت های آنلاین
    قابلیت اعتماد بیشتر
    کنترل و تغییرات پلاگین هنگام اجرا
معایب:
    هزینه بیشتر در منابع سخت افزاری و نرم افزاری
    پیچیدگی پیاده سازی

کنترل دسترسی به تغییرات با ایجاد پنل های متفاوت ui برای نقش های  Viewer, Commenter, Editor, Owner  و ساخت Sharing link
مزایا:
    کنترل بیشتر در تغییرات
    امنیت در اطلاعات اشخاص و سامانه
    سادگی پیاده سازی
    سادگی استفاده و تنظیمات آسان برای کاربر
    تغییرات آسان دسترسی
معایب:
    صرف منابع authentication , authorization


تصمیم:
استفاده از لایبرری های آماده لوکال و پیاده سازی با زبان برنامه نویسی

دلیل:
    عدم وابستگی به اینترنت و سایت های آنلاین


پیامدها:
مثبت:
    عدم وابستگی به اینترنت و سایت های آنلاین و کنترل بیشتر در تغییرات و کنترل و تغییرات پلاگین هنگام اجرا
منفی:
    پیچیدگی پیاده سازی
