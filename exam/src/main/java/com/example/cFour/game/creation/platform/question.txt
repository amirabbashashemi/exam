صورت سوال
طراحی یک پلتفرم ساخت و اجرای بازی (Game Creation Platform) مشابه Roblox / Core / Construct را طراحی کنید که:
کاربران بتوانند بدون کدنویسی یا با کدنویسی کم، بازی بسازند.
بازی‌ها روی ویندوز، لینوکس و مک اجرا شوند.
کاربران بتوانند بازی‌های خود را منتشر کنند و دیگران آن‌ها را بازی کنند.
Asset Store برای اشتراک‌گذاری مدل، صدا، انیمیشن وجود داشته باشد.
بازی‌ها بتوانند Multiplayer باشند.
سازندگان بتوانند نسخه‌بندی کنند و به نسخه‌های قبلی برگردند.
سیستم بتواند درآمد برای سازندگان ایجاد کند (Monetization).
Sandbox امن برای اجرای کدهای کاربران.
Cross-platform Runtime (موتور بازی روی سه سیستم‌عامل).
Live Update برای بازی‌های منتشرشده.
