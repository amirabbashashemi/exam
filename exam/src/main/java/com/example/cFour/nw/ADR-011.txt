ADR-011: احراز هویت با OAuth 2.0 + OIDC + JWT و MFA
وضعیت: پذیرفته شده

زمینه:
پلتفرم باید احراز هویت امن برای میلیون‌ها کاربر فراهم کنه. پسورد ساده کافی نیست. باید MFA باشه، Session امن باشه، و اگه پسورد لو بره، حساب سالم بمونه.

تصمیم:

OAuth 2.0 + OIDC با Keycloak

JWT برای Access Token (عمر ۱۵ دقیقه)

Refresh Token (Opaque، عمر ۷ روز، در HttpOnly Cookie)

MFA با TOTP (Google Authenticator) + SMS Fallback

Argon2id برای Hashing پسورد

دلیل تصمیم:
OAuth 2.0 استاندارد صنعتی برای Authorization هست. OIDC برای Authentication. JWT کوتاه‌مدت یعنی اگه لو بره، فقط ۱۵ دقیقه معتبره. MFA یعنی مهاجم حتی با پسورد، نمی‌تونه وارد بشه.

مزایا:

امنیت بالا (MFA + Argon2id)

Session امن (HttpOnly Cookie)

Revoke فوری Refresh Token

استاندارد صنعتی (Keycloak)

معایب:

پیچیدگی پیاده‌سازی (Keycloak + JWT + MFA)

تجربه کاربری سخت‌تر (MFA)

هزینه SMS برای OTP

نیاز به تیم امنیت
