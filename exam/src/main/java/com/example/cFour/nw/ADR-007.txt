ADR-007: استراتژی Deploy با Canary Release و Blue-Green
وضعیت: پذیرفته شده

زمینه:
آپدیت سیستم نباید باعث Downtime بشه. اگه نسخه جدید باگ داشته باشه، باید سریع برگردیم. کاربرا نباید متوجه آپدیت بشن.

تصمیم:

استفاده از Kubernetes + ArgoCD

Canary Release: ۵٪ ترافیک → ۲۵٪ → ۱۰۰٪

Blue-Green: دو محیط موازی، سوییچ ترافیک با یه کلیک

Rollback خودکار در صورت خطا (بر اساس Metrics)

Istio برای Traffic Shifting

دلیل تصمیم:
Canary Release اجازه می‌ده نسخه جدید رو با ترافیک کم تست کنیم. اگه خطا زیاد شد، خودکار Rollback می‌شه. Blue-Green برای تغییرات بزرگ (مثل Migration دیتابیس) استفاده می‌شه.

مزایا:

Zero Downtime (کاربر متوجه نمی‌شه)

Rollback سریع (زیر ۱ دقیقه)

تست نسخه جدید با ترافیک واقعی (۵٪)

کاهش ریسک Deploy
